# 3D Asset Sources

All environment assets are CC0 / public domain.

## Environment (`public/models/env/`)

- **Trees, bushes, grass, flowers, rocks, path tiles** — [Quaternius Stylized Nature MegaKit](https://quaternius.itch.io/stylized-nature-megakit) (CC0), Draco + WebP optimized.
- **Barrel, cardboard box, concrete barrier, trash can** — [Eclair Assets](https://eclair-assets.itch.io/) free CC0 GLB props, WebP optimized.

## Ground textures (`public/textures/`)

- `grass_color.jpg`, `grass_normal.jpg` — [ambientCG Grass001](https://ambientcg.com/view?id=Grass001) (CC0), 1K JPG.

## Weapons

- `colt1911.glb` — game viewmodel (Sketchfab, animated).
- `colt_m1911.glb`, `9mm_pistol.glb` — hero display models.
